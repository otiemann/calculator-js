# Taschenrechner

Ein einfacher Taschenrechner, programmiert in **JavaScript**, mit Unterstützung für grundlegende mathematische Operationen.

## 🚀 Funktionen

- Addition, Subtraktion, Multiplikation, Division
- Klare und benutzerfreundliche Oberfläche
- Unterstützt die Bedienung über Maus und Tastatur
- Fehlerbehandlung bei ungültigen Eingaben
  
## 🛠️ Installation & Nutzung

1. **Repository klonen:**
   ```sh
   git clone https://github.com/dein-benutzername/taschenrechner.git
   ```
2. **In das Verzeichnis wechseln:**
   ```sh
   cd taschenrechner
   ```
3. **Öffne die `index.html` in deinem Browser:**
   ```
   file:///<pfad_zur_datei>/index.html
   ```

## 🖥️ Technologie-Stack

- **HTML** – Struktur des Rechners
- **CSS** – Styling und Layout
- **JavaScript** – Logik der Berechnungen
